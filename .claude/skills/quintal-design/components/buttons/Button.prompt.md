Quintal's action button — a pill with a 44px target; use it for every commitment the family makes.

```jsx
<Button onClick={join}>Entrar na lista</Button>
<Button variant="secondary">Como funciona</Button>
<Button variant="ghost">Saber mais →</Button>
```

Variants: `primary` (butter on plum text — exactly one per screen), `secondary` (outline), `ghost` (text only). Pass `onDark` inside plum blocks. Never put white text on butter: it fails AA.
