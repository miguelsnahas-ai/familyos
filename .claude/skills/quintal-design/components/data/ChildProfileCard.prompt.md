Shows what the system knows about one child. Use the family's own words in `rows` — quoting the parent is the point.

```jsx
<ChildProfileCard
  name="Laura"
  age="2 anos e 3 meses"
  rows={[
    { label: "Rotina", value: "Acorda 7h · soneca 13h–14h30 · dorme 20h" },
    { label: "Interesses", value: "Caixas, água, empilhar objetos, música" },
  ]}
/>
```
