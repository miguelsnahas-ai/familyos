# Landing — Quintal

Recreation of the waitlist landing page, rebuilt on the Quintal design system.
Source content: the Family OS pre-launch page (https://familyos-fnnd.vercel.app),
copy kept verbatim in pt-BR; only the brand name changed to Quintal.

Sections, in order: sticky header · hero with live WhatsApp thread · the parent's
questions · four pillars · how it works (plum block) · child profile + what
Quintal is not · Family Setup + founder waitlist · footer.

Interaction: "Entrar na lista" flips the waitlist card to a confirmation state.
Everything else is static by design — this is a visual kit, not production code.
